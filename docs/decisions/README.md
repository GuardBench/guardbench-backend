# Architecture Decision Records

> Status: APPROVED
> Owner: Team
> Last reviewed: 2026-08-23
> Canonical source: GitHub
> Origin: 없음

공개 API, DB, 의존성, 아키텍처 경계 또는 되돌리기 어려운 선택은 ADR로 남긴다. 파일명은 `NNNN-short-title.md` 형식으로 순번을 붙이고 [template.md](template.md)를 복사한다.

상태는 `PROPOSED`, `ACCEPTED`, `SUPERSEDED`, `REJECTED`를 사용한다. 승인된 ADR을 바꾸려면 원문을 조용히 수정하지 말고 새 ADR로 대체한다.
